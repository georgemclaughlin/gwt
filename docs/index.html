Specs you can run

GWT

In GWT, the spec is the program. Define the input contract, run named behavior, and return typed results from the same file.

The same file can also carry GIVEN / WHEN / THEN scenarios for tests. No separate step files. No semantic handoff.

Run The Examples Read The Guide Spec Is Code
input.json rules.gwt result.json 
{
  "account": {
    "balance": 100,
    "status": "open"
  },
  "amount": 30
}
RECORD Account
  balance: number
    status: "open" | "closed"
REQUEST withdraw from account
  GIVEN account is Account
  AND amount is number
  WHEN withdraw amount from account
  OUTPUT account is Account
WHEN withdraw <amount> from <account>
  GIVEN account is Account
  REQUIRE account.status is "open"
  AND account.balance is at least amount
  subtract amount from account.balance
{
  "ok": true,
  "result": {
    "account": {
      "balance": 70,
      "status": "open"
    }
  }
}

How it works

Write It. Run It. Check It.

A GWT file shows the setup, the behavior, the input and output, and the examples that prove it works.

State Is Visible

Records and tables show the data the behavior reads and writes.

Behavior Has Names

Reusable WHEN blocks read like real workflow steps.

JSON Has A Shape

REQUEST says what input is required. OUTPUT says what result is returned.

Failure Is Clear

Missing data and bad shapes fail loudly instead of turning into silent defaults.

Examples Prove It

Scenarios live in the same file, so examples can be read and run in CI.

Try it

Run It Locally

Run Scenario Coverage

Execute the embedded vendor onboarding examples as regression tests.

python -m gwtlang test \
  examples/vendor_onboarding/rules.gwt

Call It Like An App

Send JSON state to a named request and receive the stable result envelope.

python -m gwtlang run \
  examples/vendor_onboarding/rules.gwt \
  --json-input examples/vendor_onboarding/request.json \
  --request "review vendor" \
  --json

Generate Host Types

Create TypeScript declarations from the checked request and output contracts.

python -m gwtlang types \
  examples/vendor_onboarding/rules.gwt \
  --language typescript \
  --output vendor-onboarding.d.ts

Try The Larger Stress Test

Run the MiniLang VM example that exercises records, lists, errors, and debugger state.

python -m gwtlang test \
  examples/minilang2_vm/rules.gwt

Boundaries

What GWT Is Not

GWT is not SQL, not OPA, and not a replacement for a general-purpose language. It is for workflows where the steps and checks should stay readable and runnable.
