Get Ready

You’ll use three files: delivery.gwt for the current policy, proposed.gwt for the change, and parcel.json for a customer’s request.

Run the commands below in the directory containing those files, with gwt-native installed. The current preview is available from source; a public installer is not available yet.

Developer preview: install from source and prepare the example

With Git and rustup installed, run the following in a terminal. Cargo installs the optimized executable in its bin directory, which must be on your PATH (normally configured by rustup). Use a fresh directory for this checkout and example.

git clone --branch work/native-foundation-checkpoint https://github.com/georgemclaughlin/gwt.git
cd gwt
rustup toolchain install 1.96.0
cargo +1.96.0 install --path crates/gwt-core --locked

mkdir delivery-demo
cp examples/native_delivery/rules.gwt delivery-demo/delivery.gwt
cp examples/native_review_walkthrough/candidate.gwt delivery-demo/proposed.gwt
cp examples/native_review_walkthrough/input.json delivery-demo/parcel.json
cd delivery-demo

gwt-native version --json

The command is currently named gwt-native to distinguish this engine from the earlier toolchain. The native language remains experimental.

Read The Executable Policy

The baseline charges nonmembers 5 up to 1,000g and 9 above that. Members pay zero. Parcels above 5,000g require manual handling, even for members; nonpositive weights fail.

REQUEST describes the input and output. A named WHEN block implements the behavior. DECIDE executes its first matching arm, so the order expresses policy precedence.

PROGRAM delivery quote

RECORD Parcel
  weight_grams: integer
  member: boolean

RECORD Quote
  status: "standard" | "manual"
  fee: integer

REQUEST quote delivery
  GIVEN parcel is Parcel
  GIVEN quote is Quote
    status: "standard"
    fee: 0
  WHEN quote delivery for parcel into quote
  OUTPUT quote is Quote
  THEN quote.fee >= 0

WHEN quote delivery for <parcel> into <quote>
  GIVEN parcel is Parcel
  AND quote is Quote
  REQUIRE parcel.weight_grams > 0
  DECIDE
    WHEN parcel.weight_grams > 5000
      set quote.status to "manual"
      set quote.fee to 0
    WHEN parcel.member
      set quote.status to "standard"
      set quote.fee to 0
    WHEN parcel.weight_grams <= 1000
      set quote.status to "standard"
      set quote.fee to 5
    ELSE
      set quote.status to "standard"
      set quote.fee to 9

The rest of the file contains a shared setup, a scenario, and ten example rows that check weight and membership boundaries.

Run The Proposed Change

The proposed policy in proposed.gwt extends the low-fee band to 1,500g inclusive. It updates the boundary examples and tests zero-weight rejection. Validate its 14 scenarios, then run a 1,500g nonmember request:

gwt-native validate proposed.gwt

gwt-native run proposed.gwt \
  --request "quote delivery" \
  --input parcel.json

The declared result is:

{"quote":{"status":"standard","fee":5}}

The complete run payload also includes final state, diagnostics, source identity, and execution evidence.

Compare The Same Input

Capture that same input against the baseline, then compare it with the candidate. These commands write four files in your example directory; use fresh filenames when preserving earlier reviews.

gwt-native capture delivery.gwt \
  --request "quote delivery" \
  --input parcel.json > delivery.case.json

gwt-native corpus delivery.case.json > delivery.corpus.json

gwt-native review delivery.corpus.json \
  --candidate proposed.gwt \
  --html delivery-review.html > delivery-review.json

Open delivery-review.html in your browser. Select the case and compare the fee: 9 → 5. Follow the branch and write events to the source conditions: 1500 <= 1000 was false; 1500 <= 1500 is true.

The page lets you record Pending, Accept, Reject, or Needs information, add notes, and download your decisions. The generated review starts pending. Execution evidence explains what happened; the reviewer decides whether it matches the intended policy.
