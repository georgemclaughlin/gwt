## Historical context

The Python v0.1/v0.2 specifications, `roadmap-v0.3.md`, `roadmap-v0.4.md`, their
release notes/checklists, and earlier service/client designs describe previous
implementations or proposals. They are retained as design history, not the
current language contract. See the [specification index](spec/README.md).

[Development checkpoint](development-checkpoint.md), [crash recovery](crash-recovery.md),
and [post-merge plan](post-merge-product-plan.md) also describe past checkpoints.
Use current project status and the contributor guide for today's commands and
pending work. The full chronological goal ledger is pinned from the status page.
Individual `native-*.md` design notes provide deeper feature rationale; the
current draft and executable tests govern supported behavior.
