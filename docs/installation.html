Installation

Get GWT

Run readable policies locally with a standalone executable.

Developer Preview

GWT is experimental. Public binary downloads are not available yet. The source installation below builds the same Rust engine used by the examples. Linux x86-64 is the currently qualified distribution target.

If you have a locally built binary bundle, verify its checksum, extract it, and run:

sh install.sh --prefix "$HOME/.local"
export PATH="$HOME/.local/bin:$PATH"
gwt version --json

Keep the extracted installer to remove this installation with sh install.sh --prefix "$HOME/.local" --uninstall.

Build and install from source

With Git and rustup installed, clone the repository or use your current checkout. These instructions describe the merged branch; when reviewing an unmerged change, use that change’s checkout.

git clone https://github.com/georgemclaughlin/gwt.git
cd gwt
rustup toolchain install 1.96.0
cargo +1.96.0 install --path crates/gwt-core --locked
gwt version --json

Cargo installs the optimized executable in its bin directory. Ensure that directory is on PATH. For a Cargo installation, uninstall with cargo uninstall gwt-core.

Check An Existing Installation

The version report should identify gwt-core and gwt.native-version. If it identifies gwtlang, your shell is finding the retired Python implementation.

Remove that package using its own Python environment (python -m pip uninstall gwtlang), or place the new executable’s directory first on PATH. The editor’s gwt.command setting can select an explicit path. Old programs and saved artifacts may require migration; see the upgrade guide.
