Installation

Get GWT

Run readable policies locally with a standalone executable.

Install Preview 1

Download the first GWT preview for Linux x86-64. It runs without Python or Rust. The language is experimental; this preview is for local evaluation, with no compatibility or production-support guarantee.

Choose the static Linux build unless you specifically need the GNU build. Windows, macOS, and ARM binaries are not included in this preview.

Download Linux x86-64 (static) Download its SHA-256 checksum

Save both files in the same directory. Verify the download before extracting:

sha256sum -c gwt-0.1.0-x86_64-unknown-linux-musl.tar.gz.sha256
tar -xzf gwt-0.1.0-x86_64-unknown-linux-musl.tar.gz
cd gwt-0.1.0-x86_64-unknown-linux-musl
sh install.sh --prefix "$HOME/.local"
export PATH="$HOME/.local/bin:$PATH"
gwt version --json

The version identifies package gwt-core 0.1.0 and an experimental language profile. preview-1 identifies this download; it does not assign a stable language version.

Keep the extracted installer. Run the same install command to upgrade a Rust GWT installation; remove it with sh install.sh --prefix "$HOME/.local" --uninstall.

GNU build and runtime requirements

The GNU Linux build requires glibc 2.39 or later and the shared libraries listed in its manifest. The static build has no shared-library dependencies. Both were qualified on GitHub’s Ubuntu runner; other Linux distributions and kernels are not a tested support matrix. Release assets include checksums and build provenance.

Build the preview from source

Download the qualified source package. With rustup installed, extract and build it:

tar -xzf gwt-core-0.1.0.crate
rustup toolchain install 1.96.0
cargo +1.96.0 install --path gwt-core-0.1.0 --locked
gwt version --json

Cargo installs the executable in its bin directory. Ensure that directory is on PATH. Uninstall with cargo uninstall gwt-core. This source package matches the release binaries and example. For repository development, use the contributor guide.

Check An Existing Installation

The version report should identify gwt-core and gwt.native-version. If it identifies gwtlang, your shell is finding the retired Python implementation.

Remove that package using its own Python environment (python -m pip uninstall gwtlang), or place the new executable’s directory first on PATH. The editor’s gwt.command setting can select an explicit path. Old programs and saved artifacts may require migration; see the upgrade guide.
