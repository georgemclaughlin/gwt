# Native review browser qualification — October 16, 2026

Four pages generated by the Rust CLI were exercised in Chromium with Playwright
1.63.0, in a disposable container with networking disabled during browser tests.
The available session had no connected browser tool. The browser dependency was
installed in a temporary directory outside the repository.

The pages cover three independent refund revisions (112 cases each) and seven
failure/precision/HTML-escaping cases. All 343 cases remained selectable. Checks
covered combined search/filter behavior, empty results, outcome and failure
filters, unavailable/mismatched rows, event expansion, operand navigation, and
exact-value JSON download. No page script errors, external requests, or
horizontal overflow at 390px were observed. The injected HTML/script text did
not execute. Downloaded JSON retained integer `9007199254740993` exactly.

The refund reviews showed the expected 28, 56, and 3 changed outcomes. The fault
review retained all seven rows: three compared, one baseline mismatch, and three
unavailable. One of its compared cases reproduced an execution failure; it did
not become a successful domain result just because replay verified it.

Screenshots were inspected for readable values, source context, wrapping, and
clipping. The outcome renderer was simplified to show values directly, and the
mobile layout stacks each changed field above its baseline/candidate values.
This evidence is an engineering check, not an accessibility audit or human
comprehension study.

Reproduce from the repository root in an environment with Playwright 1.63.0 and
its Chromium installed:

```sh
cargo build --locked -p gwt-core
python evaluations/native_review/generate.py /tmp/gwt-native-review-fixtures
python evaluations/native_review/check_browser.py \
  /tmp/gwt-native-review-fixtures /tmp/gwt-native-browser-results
```

Generated cases, full JSON, and HTML stay in the selected fixture directory.
Rebuild and regenerate together when Rust source changes, since captured cases
bind the native engine source fingerprint. The native review workflow itself
does not require Python or Playwright.
